A simple audio file sampler

How to use in non-UI DAWs like yadaw: Either select slot in ui and toggle "Pick to Slot" to true (make sure play the track once in yadaw, to open the file picker), or copy a file to ~/.local/share/MamplerSlots/slots/slot_000.wav (any common audio extension), then toggle "Reload Slot" or switch to that slot number.
